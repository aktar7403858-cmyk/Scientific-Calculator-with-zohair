# Scientific Calculator

A responsive scientific calculator made with HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, division, and remainder
- Powers and factorials
- Square root, absolute value, and exponential function
- Sine, cosine, and tangent
- Common logarithm (`log`) and natural logarithm (`ln`)
- Constants π and e, plus previous answer (`Ans`)
- Degrees/radians toggle for trigonometric functions
- Keyboard support and responsive layout

## Run
Open `index.html` in a modern web browser. No installation or external libraries are needed.

## Files
- `index.html` — page structure
- `style.css` — appearance and responsive layout
- `script.js` — calculator logic
